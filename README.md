# FREDMEN
A mobile-first, map-based social discovery app that lets strangers form and join real-world public groups nearby, with safety-first design and real-time interaction.

## About

**FREDMEN** (derived from "Fremden" - German for "strangers") is a location-based social platform designed to help people discover and join spontaneous, real-world meetups in their city. Instead of showing individual profiles, FREDMEN displays groups and activities on a map, emphasizing social contexts over personal browsing.

### Core Features
- 🗺️ **Map-based discovery** — Find groups and meetups pinned near you
- 👥 **Context over profiles** — Join activities, not individuals
- 🛡️ **Safety-first design** — Phone verification, moderation, panic exit features
- ⚡ **Low-friction joining** — One-tap to join public groups
- 💬 **Real-time chat** — Connect with group members instantly

### Target Launch Markets
Initial focus on Indian Tier-1/Tier-2 cities (Bangalore, Mumbai, Delhi, Pune) and university hubs.
